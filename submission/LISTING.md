## Long description

Codex Pet Maker guides users from a reference image or text description to a
complete Codex v2 animated pet. It keeps generation resumable, emits one compact
next action, retries only failed stages, assembles and validates the 8×11
animation atlas, checks all viewing directions, and packages the final pet for
installation. User media and generated artifacts stay outside the Plugin
source, and every run uses only the current user's inputs.

## Data handling summary

The Plugin has no independent remote server, analytics, advertising, or
background telemetry. References and generated assets stay in an isolated run
directory. If a workflow requests image generation, only the current run's
attached references are sent to the configured image-generation service.
