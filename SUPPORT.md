# Support

## Get help

Use
[GitHub Issues](https://github.com/haishanstudying/codex-pet-maker-public/issues)
for installation, validation, packaging, and documentation problems.

Before opening an issue:

1. Check the current [README](README.md) installation and update steps.
2. Restart Codex or the ChatGPT desktop app and test in a new task.
3. Reproduce the problem with synthetic data when possible.

Include:

- the Plugin version;
- the Codex surface and operating system;
- the smallest reproducible prompt or command;
- the expected and observed behavior; and
- redacted validation output when relevant.

## Protect private data

Do not post reference images, generated pets, prompts containing personal data,
access tokens, credentials, private paths, or unredacted run logs in a public
Issue. Replace private assets with a synthetic geometric fixture.

## Security reports

Do not report vulnerabilities in a public Issue. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting when
available.

## Scope

Support is best effort. The maintainer can help with reproducible Plugin
behavior but cannot provide support for third-party image-generation services,
account access, billing, or content ownership disputes.
